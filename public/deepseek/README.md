# STRANDBOUND · 弦缚

> 「在活着的黑暗里，唱一支自己的歌。」
> 太空歌剧 · 生物收集 RPG · 桌面端（浏览器运行，无需安装）

你是最后一名 **织弦者**，驾驶以濒死生物 Moth 为心核的活船 **Cytha**，穿行于即将被「沉默」吞噬的子午纱幕星区。与异星生命 **弦灵** 建立共鸣羁绊，查明沉默的真相，为宇宙重新唱出和弦。

---

## 快速开始

**方式一（推荐）**：直接双击 `index.html`，用任意现代浏览器打开即可游玩（支持 Chrome / Edge / Safari / Firefox）。

**方式二（本地服务器）**：

```bash
python3 -m http.server 8123
# 浏览器打开 http://localhost:8123
```

无需构建、无需依赖——游戏本体是纯 HTML5 Canvas + 原生 ES 模块，零第三方运行时库。存档保存在浏览器 localStorage 中。

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动（点按走一步，按住连续走） |
| E / Enter / 空格 | 确认 / 互动 / 对话推进 |
| Esc | 打开暂停菜单 / 关闭界面 |
| ←→ / ↑↓ | 菜单选择 |
| 鼠标 | 全部菜单均可点击；点击推进对话 |

- 撞上地图上游荡的野生弦灵即进入战斗。
- 站在 NPC / 物品 / 出口旁按 E 互动；踩上出口（着陆台、信标、Boss 门）会自动触发。

## 玩法概要

- **结契而非捕捉**：战斗中通过「观测 / 安抚 / 攻击」积累**共鸣**，共鸣达标后执行「结契」。每种弦灵有自己的**性情**（好奇 / 惊怯 / 骄傲 / 羞怯 / 戒备 / 耐心），获取方式各不相同。
- **共振相克**：棱光 > 幽黯，潮汐 > 烬火，鸣响 > 生发（克制 1.5 倍，被克 0.75 倍）；隐藏的 **纯弦** 无相克。
- **战斗**：3v3 回合制，共鸣点（RP）驱动招式、张力攒满可放「咏叹」；换人有登场被动；Boss 分阶段 AI，不是大血包。
- **船光推进**：已结契弦灵的等级决定船光，船光不足无法前往更深的星区——收集与探索互相成就。
- **歌锁**：需要对应共振的弦灵才能打开，值得回头重访。
- **成长**：升级学招（最高 15 级）、光露果永久培育属性、歌者之泪让特定弦灵**蜕变**。
- **主线 3 幕 9 章**：教学结契 → 信标 → 碎晶王 → 烬灰浅滩（支线）→ 中空尖塔 → 归档者 → 深底渊 → 溺没合唱 → **中途抉择** → 伤口区 → 空洞合唱团 → 沉默的回声 → 结局（结局随你的选择与图鉴完成度变化）。
- **隐藏内容**：集齐六种共振，可在深底渊祭坛唤醒第十三物种「初声」。

## 存档

- 3 个手动槽位 + 进入区域时的自动存档。
- 保存内容：队伍 / 名册 / 背包 / 任务与剧情旗标 / 世界状态 / 图鉴 / 设置 / 时长 / 种子。
- 存档经过版本化 + 结构校验，损坏存档会被识别而不会崩溃游戏。

## 开发

```bash
npm install --include=dev   # 仅开发需要（Playwright 测试）
npm test                    # 单元测试（战斗规则 / 存档往返 / 数据完整性，15 项）
node tests/e2e/smoke.mjs    # 启动冒烟 + 截图
node tests/e2e/newgame.mjs  # 新玩家全流程（新游戏→教学结契→存读档一致）
node tests/e2e/story.mjs    # 主线速通（4 Boss→抉择→结局→标题）
node tests/e2e/menus.mjs    # 菜单巡览截图
node tests/e2e/secrets.mjs  # 隐藏内容（初声/蜕变）
node tests/e2e/battle.mjs   # 战斗交互
node tests/e2e/capture.mjs  # 结契流程
```

调试入口：`index.html?debug=battle`（直接战斗）、`index.html?debug=world`（带强队伍探索）。

