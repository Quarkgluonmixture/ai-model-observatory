# Agent 101 V2 design note

Understanding-first redesign of `/presentation/agent-101`.

- explanatory copy is primary; display headings are secondary
- one green hue family, no dark showcase section
- API / API Key / model / input are explained before code
- Agent is taught as an execution loop around an LLM, not as a magical new model
- Skills are presented as runtime-dependent reusable instructions/scripts/examples, not a universal installable package format
- GitHub download is separated from compatibility/install
- MCP is contrasted with Skill instead of taught as another buzzword
- mathematical-modeling usage is framed as human judgement + tool-assisted execution
